# Диабет-бот (Telegram, Python / aiogram)

Бот для пациентов с сахарным диабетом и врачей-эндокринологов.

## Что реализовано на этом шаге

- **Регистрация пациента**: пошаговый опрос (ФИО, пол, возраст, город, стаж
  диабета, рост, вес, терапия, телефон), сохранение карты пациента в SQLite.
- **Регистрация врача**: пошаговый опрос (ФИО, город, место работы,
  специальность, опыт работы), сохранение анкеты со статусом `pending`
  (ожидает подтверждения администратором).
- Определение роли при `/start` (пациент / врач) и повторный вход для уже
  зарегистрированных пользователей (бот "узнаёт" пользователя по Telegram ID).
- База данных SQLite (`diabet_bot.db`), создаётся автоматически при первом
  запуске.
- **Школа диабета**: все 9 категорий из ТЗ (Частые вопросы, Самоконтроль,
  Питание, Инсулин, Гипогликемия, Гипергликемия, Диабет и сопутствующие
  заболевания, Физкультура и спорт, Дополнительные вопросы) — всего 51
  вопрос с ответами. Навигация через inline-кнопки: категории → вопросы в
  категории → ответ → кнопки «Назад».
- **Админ-панель** (через список `ADMIN_IDS` в `.env`, без отдельной
  регистрации):
  - при подаче новой заявки врача администраторам сразу приходит уведомление
    с карточкой врача и кнопками «✅ Одобрить» / «❌ Отклонить»;
  - команда `/admin` — показывает все заявки со статусом «на рассмотрении»;
  - команда `/doctors` — показывает всех врачей в базе (с кнопкой
    «🗑 Удалить» для уже одобренных/отклонённых);
  - врач получает уведомление в бота о результате рассмотрения его заявки.

## Что будет реализовано дальше (по ТЗ)

- Меню «Связь с врачом»: список одобренных врачей + «Любой врач», переход по
  диплинку `t.me/<username>` на переписку с врачом.
- Кабинет врача: список пациентов, просмотр карты пациента, переход в диалог.
- Кабинет администратора: подтверждение/отклонение заявок врачей, удаление
  врачей и т.д.

## Структура проекта

```
diabetbot/
├── main.py                  # точка входа, запуск бота
├── config.py                 # загрузка токена и настроек из .env
├── requirements.txt
├── .env.example
├── database/
│   └── db.py                 # SQLite: схема таблиц и CRUD-функции
├── states/
│   └── states.py             # FSM-состояния регистрации
├── keyboards/
│   └── keyboards.py          # клавиатуры (выбор роли, пол, телефон, меню)
├── content/
│   └── school_data.py        # контент Школы диабета: категории, вопросы, ответы
└── handlers/
    ├── start.py               # /start, выбор роли, приветствие
    ├── patient_reg.py         # пошаговая регистрация пациента
    ├── doctor_reg.py          # пошаговая регистрация врача
    ├── school.py               # навигация по Школе диабета (inline-кнопки)
    └── admin.py                # /admin, /doctors — одобрение заявок врачей
```

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и вставьте токен бота, полученный у
   [@BotFather](https://t.me/BotFather):

   ```bash
   cp .env .env
   # затем отредактируйте .env и укажите BOT_TOKEN=...
   ```

   Чтобы стать администратором, узнайте свой Telegram ID через
   [@userinfobot](https://t.me/userinfobot) и впишите его в `ADMIN_IDS`
   в том же файле `.env` (несколько ID — через запятую).

3. Запустите бота:

   ```bash
   python main.py
   ```

4. Откройте бота в Telegram и отправьте `/start`.

## Технические решения

- **aiogram 3.x** — современный асинхронный фреймворк, официальный
  рекомендуемый вариант для новых Telegram-ботов на Python.
- **SQLite (через aiosqlite)** — простое файловое хранилище, достаточное для
  старта и тестирования. При росте нагрузки таблицы `patients` и `doctors`
  можно перенести на PostgreSQL, изменив только модуль `database/db.py` —
  остальной код (handlers) трогать не придётся.
- **FSM (машина состояний aiogram)** — используется для пошагового сбора
  анкетных данных пациента и врача с валидацией каждого поля.
- Telegram ID пользователя используется как первичный ключ, поэтому бот
  автоматически распознаёт уже зарегистрированных пациентов и врачей при
  повторном `/start`.
